## Usage

```sh
pom list ruby --remote / -r
pom list ruby [ --local ]

pom install ruby -v 2.7
pom install ruby -v 3.0
pom install ruby -v head
pom install jruby -v 10.0
pom install node

pom use ruby -v 3.4
pom use node
```
